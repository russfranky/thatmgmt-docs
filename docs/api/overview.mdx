# API reference overview

Every page in this reference is generated from the real OpenAPI spec (`spec/openapi.json` in this repo, copied from `docs/openapi.json` on thatmgmt main). Nothing here is hand-written, so the reference cannot drift from the API.

- Base URL: `https://api.thatmgmt.com`
- Auth: Bearer <redacted> (JWT) on all routes except the health probes.
- The spec lists 48 operations across 13 groups.
- Response envelopes vary per route; the spec does not publish field-level response schemas. Each endpoint documents its status codes and the error model from the spec.

## Regenerating

When the spec changes, refresh `spec/openapi.json` from thatmgmt main and run:

```bash
python3 scripts/generate-api-reference.py spec/openapi.json --out docs/api
```

The script fails if any route is ungrouped or the count mismatches, so a bad generation cannot ship silently.
