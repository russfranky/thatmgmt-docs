# Check availability

`GET /v1/domains/availability` checks whether a domain is available through the supplier. It is read-only and never reserves or registers anything.

```bash
curl -H "Authorization: Bearer $TMGMT_API_KEY" \
  "https://api.thatmgmt.com/v1/domains/availability?domain=example.com"
```

## Parameters

| Name | Required | Description |
| --- | --- | --- |
| `domain` | yes | Fully qualified domain name to check. |
| `optimizeFor` | no | `SPEED` or `ACCURACY`. |

Use `optimizeFor=SPEED` when you are scanning many names, and `optimizeFor=ACCURACY` when the result feeds a quote or a customer-facing answer.

## Price note

Availability responses may include prices. Treat those as indicative only: they are not verified account-specific wholesale costs. Only a [locked quote](/guides/quote) is a verified price.

## Responses

`200` returns the availability result. `401` means the key is missing or invalid. `503` means the route composition is not wired.
